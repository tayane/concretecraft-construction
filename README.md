# 🏗️ ConcreteCraft Solutions — Construction & Concrete Website

A modern, high-performance, and fully responsive multi-section landing page built for **ConcreteCraft Solutions**, a structural engineering and concrete services company. 

This project showcases a clean industrial design, an interactive quote request calculator, a filterable gallery, and mobile-friendly navigation.

## ✨ Features

- **Responsive & Mobile-First Design**: Smooth layout adaptation across smartphones, tablets, and desktops.
- **Interactive Quote Calculator**: Real-time project scope cost estimator based on concrete volume, finish type, and project scale.
- **Filterable Gallery**: Dynamic portfolio filtering by project category (Commercial, Residential, Infrastructure, Decorative).
- **Interactive Testimonial Carousel**: Customer proof slider with auto-rotation and manual controls.
- **Contact & Location Info**: Comprehensive contact section featuring interactive modal quote triggers, working hours, and contact details.
- **Clean Industrial Aesthetic**: Custom slate, concrete gray, and safety amber color palette tailored for heavy civil engineering.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for accessibility and SEO optimization.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid, animations, and media queries (no external frameworks required).
- **JavaScript (ES6+)**: DOM manipulation, filter logic, dynamic pricing calculation, and slider state management.
- **Lucide Icons**: Clean, light SVG icons via CDN.
